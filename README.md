# YUWNXU — портфолио

Сайт-портфолио в виде ретро-игры: стартовый экран, выбор уровня (проекты), страница каждого проекта, навыки персонажа и финальный диалог со связью. Чистые HTML, CSS и JavaScript, без фреймворков и сборщика.

## Что внутри

- **Старт**, **Выбор уровня**, **Проект**, **Навыки**, **Связь** — пять экранов с переходом «пиксельной шторкой».
- Управление клавиатурой (стрелки, Enter, Esc) и касанием.
- Фильтр проектов Mobile / Web, переходы между проектами стрелками.
- Адаптивная вёрстка для телефона.
- Учитывается `prefers-reduced-motion`: при отключённых анимациях всё работает без них.

## Структура

```
index.html
css/        base, layout, components, screens, motion
js/
  main.js         маршруты
  core/           роутер, переходы, клавиатура, DOM-хелпер
  data/           проекты, навыки, контакты (весь контент здесь)
  ui/
    components/   кнопка, меню, рамки, персонаж, облака…
    screens/      пять экранов
assets/           логотипы, медиа проектов
```

Контент меняется только в `js/data/`: добавить проект — значит добавить объект в `projects.js` и положить картинку в `assets/media/`.

## Запуск

ES-модули требуют сервер:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000.
